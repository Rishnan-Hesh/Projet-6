Projet Vitesse avec utilisation de packages pour la première fois.

Description:
L'application Vitesse a pour but de garder en mémoire une liste de candidats que l'on peut selectionner pour accéder à des informations les concernant. 
Le compte administrateur peut également les ajouter en favoris pour les retrouver plus facilement.
